# Sim2Real 実践帳

`index.html` は単体で完結した教材です。ブラウザで開くだけで読めます（依存なし、
フォントのみ Google Fonts から取得）。

    xdg-open handbook/index.html

MuJoCo でのモデル作成から強化学習、実機同定、M5Stack へのデプロイまでを、この
リポジトリで実際に測った数値と、実際に踏んだ失敗で追いかけます。図はすべて実データ
から起こしたもので、ステップ応答は `scripts/export_policy.py` が扱うのと同じ run、
摩擦スイープは `scripts/friction_test.py` の実測値です。

数値を更新したときは、本文の該当箇所も直してください。教材の価値は数字が本物である
ことなので、モデルだけ更新して本文が古いままになるのがいちばん困ります。
